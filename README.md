# Photonex

Editor de imágenes de la suite Jacnex: capas, máscaras, texto y archivos PSD reales.

Se instala y actualiza desde [Jacnex Studio](https://github.com/jacnexstudio/jacnex-studio).
Descargas: [versiones publicadas](https://github.com/jacnexstudio/photocraft/releases).

Basado en [PhotoCraft](https://github.com/storytold/photocraft) (MIT o Apache-2.0), con la marca Jacnex.
Cómo se compila: [jacnex-build](https://github.com/jacnexstudio/jacnex-build).
Jacnex no está afiliado ni respaldado por el ArtCraft Team.
